Создаю и развиваю прикладные решения: ИИ-инструменты, базы знаний, CRM и веб-сервисы. Соединяю личную разработку с опытом бизнес-анализа, системной архитектуры и внедрения корпоративных систем.

Работаю с задачей от требований и модели данных до реализации, интеграций и дальнейших доработок. Использую ИИ для разработки, уделяю внимание проверке результата, документации и сопровождению.

## Направления работы

- **ИИ и базы знаний:** промпт-инжиниринг, LLM API, RAG, поиск по документам, память и инструменты агентов.
- **Автоматизация бизнеса:** CRM, обработка заявок, уведомления, API и webhooks, обмен данными между системами.
- **Веб-разработка:** серверная логика, базы данных, авторизация, интерфейсы и собственные темы WordPress.

## Инструменты и технологии

- **Разработка с ИИ:** Cursor, Claude Code, Codex, Hermes.
- **Backend и данные:** Python, FastAPI, Flask, SQLAlchemy, PostgreSQL, SQLite, Alembic.
- **ИИ и интеграции:** OpenAI-совместимые API, Docling, Qdrant, RAG, MCP, REST, JSON.
- **Веб-разработка:** Jinja2, HTMX, WordPress/PHP, Gutenberg, Pods.
- **Качество и инфраструктура:** Git, Docker, pytest, ruff, Playwright.

Профильная подготовка Zerocoder: промпт-инжиниринг, no-code автоматизация на n8n и Albato, автономные агенты и визуальный контент с ИИ.
